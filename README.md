# Mapa radial de biografías de Jorge Eduardo Eielson

Visualización interactiva construida con D3.js.

## Uso

1. Abra `index.html` con doble clic.
2. Use la rueda para acercar/alejar y arrastre para desplazar el mapa.
3. Haga clic en una rama o dato para revisar la fuente y su relación con otras versiones.
4. El botón **Exportar SVG** genera una versión vectorial del estado actual del mapa.

La biblioteca D3 está incluida localmente, por lo que el mapa funciona sin conexión. Los enlaces a las fuentes oficiales requieren internet.
